DevKart final responsive website.
- English premium layout based on the supplied reference design.
- Local product images and 4-image product galleries.
- Responsive mobile + desktop layout.
- Login/signup demo, OTP demo, cart login gate, search and category filtering.
- Wishlist, profile, addresses, orders and Cash on Delivery checkout demo.
- Browser localStorage is used for demo data. Real SMS OTP/backend/payment is not included.
- Validation improvements: stock limits, safer rendering of user-entered text, invalid-cart cleanup, total cart quantity badge, email validation.
- Upload the contents of this folder to the GitHub Pages repository root.


ADMIN CONTROL PANEL
- Open admin.html on the same domain/browser as index.html.
- Demo admin login: username admin, password admin123.
- Manage products (add/edit/delete, price, MRP, stock, image filename/URL, description), order status and customer list.
- Product changes are saved in localStorage and the store loads the saved catalog on refresh.
- IMPORTANT: This is a static/demo admin panel. The login is not secure and data is browser-local. For a production store, use a server/backend database and real admin authentication.
