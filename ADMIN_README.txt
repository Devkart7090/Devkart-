DevKart Admin Control Panel
============================

Open admin.html from the SAME GitHub Pages site to share localStorage with index.html:
https://YOUR-USERNAME.github.io/YOUR-REPO/admin.html

Features:
- Dashboard
- Orders + status update/delete
- Products add/edit/delete
- Customers
- Addresses
- Wishlist
- Website settings

Important:
This is a frontend/localStorage admin panel. It is NOT secure for real customer data and does not sync between devices. For production use, connect the store and admin panel to a real backend/database and protected admin authentication.
